# courseware

英语讲练课件仓库（天津高考英语真题讲练）。

## 目录结构
- `cloze/` — 完形填空讲练课件（cloze-courseware 产出）
- `reading/` — 阅读理解讲练课件（reading-courseware 产出）
- `expression/` — 阅读表达讲练课件（expression-courseware 产出）
- `writing/` — 书面表达 / 作文
- `papers/` — 试卷精校版（exam-paper-builder 产出）
- `docs/` — 说明与素材
